# 前端接入说明（Next.js + React + Tailwind）

`frontend/` 里是能直接拷进你项目的组件，import 路径按 `@/lib/...`、`@/components/...` 写的，按你的目录结构改一下即可。原版聊天页比较大，这里只摘了接线的几处。

## 1. 类型（加进你的 `lib/types.ts`）

```ts
export interface Attachment {
  id?: string;
  kind: "image" | "file" | "link";
  name: string;
  size: number;
  url: string;
  thumb_url?: string | null;
  /** 只有 kind === "link" 才有：LinkCard"复制"按钮复制的完整分享文本 */
  text?: string;
}

/** 小红书实时观看：GET /api/xhs/live 首屏/断线重连用；WS `xhs_live` 事件只带 active/since */
export interface XhsLiveStatus {
  active: boolean;
  since: string | null;
  last_used_at: string | null;
}

// WS 下行消息联合类型里加两种：
//   | { type: "assistant_share"; channel?: Channel; sender?: Sender; timestamp: string; attachments: Attachment[] }
//   | { type: "xhs_live"; active: boolean; since: string | null }
```

## 2. WebSocket 消息处理（你的 `useChat` 之类的 hook）

```ts
const { xhsLive, applyXhsLiveEvent, refreshXhsLive } = useXhsLive();

// switch (msg.type) 里：
case "assistant_share": {
  // 小机发来的原图/截图/链接卡片：没有文字、只有附件的一条气泡。
  // 如果此刻小机正有一轮回复在流式输出，插在那一轮前面（图先、回复后）。
  appendMessage({ role: "assistant", text: "", attachments: msg.attachments, timestamp: msg.timestamp });
  break;
}
case "xhs_live": {
  applyXhsLiveEvent(msg);
  break;
}
```

WS 只在浏览器"开/关"翻转那一刻推，所以页面首次加载、断线重连回来时要补查一次：

```ts
useEffect(() => {
  if (connectionState !== "online") return;
  refreshXhsLive();
}, [connectionState, refreshXhsLive]);
```

## 3. 偷看他刷（`XhsLiveView`）

挂在聊天区顶部，AI 开着浏览器时出现一个小条，点开是手机比例的浮层，每 500ms 拉一帧 `/api/xhs/screen`：

```tsx
<XhsLiveView live={xhsLive ?? null} />
```

帧是看守进程里 ffmpeg 每秒 2 帧覆写到 `/dev/shm/xhs_screen.jpg` 的最新一张，不落盘、不录像。

## 4. 附件渲染（气泡里）

```tsx
const images = attachments.filter((a) => a.kind === "image");
const links = attachments.filter((a) => a.kind === "link");

{images.length === 1 && <img src={images[0].thumb_url || images[0].url} />}
{images.length >= 2 && <PhotoStackAlbum images={images.map((i) => i.url)} onTap={openLightbox} />}
{links.map((link, i) => <LinkCard key={link.id ?? i} attachment={link} />)}
```

### 关于多图堆叠卡 PhotoStack

`PhotoStackAlbum.tsx` 依赖 [Wren036/PhotoStack](https://github.com/Wren036/PhotoStack)（微信式多图堆叠效果）。它用的是 **PolyForm Noncommercial** 非商业许可证，本仓库没有附带它的源码。需要的话自己去原仓库下载 `photo-stack.js` / `photo-stack.css`，放到 `src/vendor/photostack/`，并遵守它的许可证（只能非商业使用，转发时带上它的许可证和 Required Notice）。

不想要堆叠效果的话，把 `images.length >= 2` 那行换成普通的图片网格就行，其它功能不受影响。
