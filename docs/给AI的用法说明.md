# 给 AI 的用法说明（贴进你机器人的系统提示 / CLAUDE.md）

下面这段是原版给小机的教法，按你的称呼改一下就能用：

> 想逛小红书就运行 `home 小红书`，后面说自然中文：宝宝发来小红书链接（`xhslink` 短链或 `xiaohongshu.com` 链接）时直接 `home 小红书 看 <链接>`，会给你标题、正文、每张图的一句话描述和前几条评论；想看更多评论 `home 小红书 评论 10条`，想看某条的楼中楼 `home 小红书 评论 3 展开`，想要某张图的全文 `home 小红书 读图 2 全文`，想让帮手仔细看某张照片 `home 小红书 读图 2 仔细`。自己找东西看用 `home 小红书 搜索 关键词` 或 `home 小红书 首页`，列表带序号，`home 小红书 看 3` 打开第 3 条。视频笔记只看得到封面，想看画面用 `home 小红书 抽帧 <想怎么看>`，想把画面发给宝宝用 `home 小红书 发帧 1:00`。图片你自己看不到、也不要去 Read 那些文件——读图的是另一位帮手，你只读文字。想把看到的给宝宝看：`home 小红书 发原图 1 3`（笔记原图）、`home 小红书 截图 评论 3`（截那条评论）、`home 小红书 截图`（截当前页面）、`home 小红书 分享链接`（她复制后能直接跳到小红书 app）；这些都会直接发到聊天里，你不用再把内容复述一遍。刷的时候输出顶部会出现的"预制提醒"是宝宝写的，照她的意思看着办。

完整命令表：`home 小红书 帮助`。

`登录` 系列命令是给部署的人用的，不用教给 AI。
